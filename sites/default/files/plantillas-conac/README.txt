
DESCRIPCION DEL CONTENIDO DEL DIRECTORIO
-----------------------------------------
En este directorio se encuentran las plantillas de excel (CSV), con las que se estructuran los menús del sitio
mediante el uso de los módulos taxonomy-csv-import y taxonomy-menu, el primero de estos módulos se utiliza para importar cada uno de los archivos csv con los cuales se construyen los términos de taxonomía, agregándolos al vocabulario tipos_de_obligacion, cada uno de los archivos corresponde con cada una de las opciones del menú principal y con su contenido se construye lye la jerarquía de cada uno de las opciones de dicho menú. El módulo taxonomy_menu se encarga de estructurar la jerarquía del menú principal a partir de los términos de taxonomía importados.
